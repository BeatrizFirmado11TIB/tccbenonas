Dispositivo Final Montado

O Petrotech é um dispositivo compacto e robusto, projetado especificamente para ambientes industriais agressivos. Totalmente selado e protegido contra água, poeira e impactos.

  • Processamento InteligenteESP32 de última geração
  • Conectividade DuplaWiFi + GSM para máxima confiabilidade
  • Autonomia EstendidaAté 30 dias de operação contínua
  • Alta PrecisãoSensor industrial certificado

Componentes do Sistema

Sensor de Pressão para Arduino G1/4

Sensor que mede a pressão de líquidos e gases e envia os dados ao Arduino para monitoramento.

Valor UnitárioR$138,00

Microcontrolador ESP32 com Wi-Fi

Processador com WiFi/Bluetooth integrado para transmissão de dados.

Valor UnitárioR$ 35,00

LEDs de status

Indicadores visuais que mostram o estado do sistema (ligado, alerta ou normal).

Valor UnitárioR$ 5,00

Fonte de alimentação 12V/2A

Converte a energia da tomada para 12V, alimentando o ESP32 e a bomba d'água.

Valor UnitárioR$ 55,00

Cabos e conectores

Fios jumpers que fazem as ligações elétricas entre todos os componentes.

Valor UnitárioR$ 40,00

Protoboard

Base de ensaio sem solda para montar e testar o circuito do protótipo.

Valor UnitárioR$ 8,00

Bomba d'água

Motor que bombeia água para simular o fluxo no sistema monitorado.

Valor UnitárioR$ 30,00

Display LCD

Tela que exibe em tempo real os valores de pressão e alertas do sistema.

Valor UnitárioR$ 30,00

Buzzer

Emite sons de alarme quando a pressão ultrapassa os limites seguros.

Valor UnitárioR$ 8,00
